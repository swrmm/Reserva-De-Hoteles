GUIA DE EVALUACION - API REST RESERVA DE HOTEL
================================================

Proyecto:
API REST para reserva de hotel usando Node.js, Express y MySQL.

Carpeta del proyecto:
C:\Users\Fabiant\Desktop\Proyecto Web 2

Objetivo:
Construir una API REST basica pero completa para administrar usuarios, habitaciones,
reservas, disponibilidad, extras y un resumen tipo dashboard.


1. TECNOLOGIAS USADAS
---------------------

Backend:
- Node.js
- Express

Base de datos:
- MySQL
- mysql2

Autenticacion:
- bcryptjs para encriptar passwords
- jsonwebtoken para generar JWT

Configuracion:
- dotenv
- cors

Pruebas:
- Postman

7. COMENTARIO PARA DEFENSA
--------------------------

Este proyecto esta hecho como una API REST basica y evaluable.
No es una aplicacion frontend, sino un backend probado por Postman.

La idea principal es demostrar:
- estructura clara de API REST,
- conexion a base de datos,
- autenticacion con JWT,
- modelos de hotel,
- CRUD de habitaciones y reservas,
- validaciones basicas,
- errores claros,
- coleccion Postman,
- planificacion por hitos,
- migracion adicional de esquema.

Si preguntan por que se usa MySQL y no PostgreSQL/Sequelize:
Se uso MySQL con mysql2 porque el proyecto base ya estaba construido asi y permite
cumplir los requerimientos de forma simple, directa y facil de probar.

Si preguntan por el reset de password:
Es un flujo demo para evaluacion. En un sistema real el token se enviaria por email,
pero aqui se devuelve como token_demo para poder verificarlo en Postman.

Si preguntan por las rutas protegidas:
Primero se hace login, luego se copia el token JWT y se envia en Authorization Bearer.

Si preguntan por el calculo de total:
El backend calcula total = noches * precio_noche + extras_total, para evitar que el
cliente manipule el precio final.
